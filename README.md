# SmartDoor — 얼굴인식 스마트 도어락

라즈베리파이와 카메라를 이용해 얼굴을 검출하고, 등록 사용자와 비교해 문을 여는 스마트 도어락 프로젝트입니다.

## 프로젝트 목표 및 기술

초음파 센서로 접근을 감지하고, 카메라에서 얼굴을 검출해 로컬에 저장한 뒤 등록 사용자와 비교합니다. 일치하면 서보모터로 문을 열고 부저로 결과를 알리는 흐름을 목표로 합니다.

- Python, OpenCV: 카메라 입력, 얼굴·눈 검출, 이미지 저장
- Tkinter, Pillow: 화면 구성 및 영상 표시
- face_recognition, NumPy: 얼굴 특징값 추출 및 비교
- Raspberry Pi GPIO: 센서와 구동 장치 제어 예정

기존 자료에는 Python 3.6과 3.9가 함께 기록되어 있어 공통 실행 환경은 확정되지 않았습니다.

## 담당 기능: 얼굴 검출 및 로컬 저장

[얼굴 검출·저장 코드](archive/experiments/facedetect_10_13.py)에 다음 기능을 구현했습니다.

1. 카메라 프레임 읽기
2. 회색조 변환 및 히스토그램 평활화
3. Haar Cascade로 얼굴 영역 검출
4. 검출된 얼굴 영역에서 눈 검출 수행
5. 얼굴 검출 시 전체 프레임을 `self camera test1.jpg`로 저장

얼굴만 잘라낸 이미지가 아닌 전체 프레임을 저장합니다. 파일명이 고정되어 덮어쓰며, 사용자별 누적 저장 기능은 없습니다. 저장 위치는 실행 시 현재 작업 디렉터리입니다. 저장 성공 여부를 검사하는 코드는 없으며 현재 환경에서 실제 카메라와 저장 동작은 재검증하지 않았습니다.

## 전체 진행 현황

| 기능 | 현재 상태 | 위치 |
|---|---|---|
| 얼굴 검출·로컬 저장 | 개별 실험 코드에 구현 | `archive/experiments/facedetect_10_13.py` |
| 실시간 카메라 화면 | 이전 버전에 Tkinter 연동 코드 존재 | `archive/versions/door/src/main.py`, `archive/experiments/tkinter_cam.py` |
| 메인 화면·등록 패널 | 사진 없는 미리보기 영역과 이름·비밀번호 입력창 구현 | `src/main.py` |
| 사용자 등록 | 결과 문구 표시, 실제 데이터 저장 미연결 | `src/main.py` |
| 얼굴 특징값 비교 | 코드 작성, 필요한 모듈 누락 및 오류 존재 | `src/Sensor/FaceClassifier.py` |
| 얼굴·눈 검출 모듈 | 예제 작성, 보조 파일 누락 | `src/Sensor/Camera.py` |
| 초음파·서보모터·부저 | 골격 작성, GPIO 부분 주석 처리 | `src/Sensor/SensorController.py` |
| 전체 기능 통합 | 추가 연동 및 장치 테스트 필요 | 프로젝트 전체 |

현재 메인 화면에는 얼굴 검출·저장과 센서 제어가 연결되지 않았습니다.

## 실행 및 검증 상태

- 정리 전 Python 파일 29개의 문법 검사 통과
- 확인한 Python 환경에서 OpenCV, face_recognition, imutils 미설치
- 루트 코드에 `person_db.py`, `video.py`, `common.py` 누락
- Cascade XML과 OpenCV fallback 예제 데이터 미포함
- 의존성 목록은 비어 있고 `setup.py`에 샘플 설정이 남아 있음
- 기존 개인 사진 로딩을 제거하고 중립적인 미리보기 영역으로 변경
- 등록 확인에 사용하던 고정 비밀번호 제거, `SMARTDOOR_ADMIN_PASSWORD` 환경변수 사용
- 실제 카메라 촬영, 파일 저장, GPIO 및 문 개폐는 현재 환경에서 미검증

현재는 전체 기능이 바로 실행되는 상태가 아닙니다. 기능 연동이나 누락 의존성은 해결하지 않았습니다. 개인정보 제거를 위해 사진 표시, 작성자 설정 및 고정 비밀번호 관련 코드만 변경했습니다. 보관 코드의 홈 경로는 사용자명을 익명화한 예시이므로 실제 장치에 맞게 설정해야 합니다. 관리자 비밀번호 환경변수를 설정하지 않으면 등록 성공을 표시하지 않습니다.
