3. Docker 환경 설정 기록

과거 메모의 순서이며 현재 프로젝트에 Dockerfile이 제공된다는 의미는 아닙니다.

WSL2:

https://javaworld.co.kr/131
https://docs.microsoft.com/ko-kr/windows/wsl/install

Docker:
https://docs.docker.com/desktop/windows/install/

face_recognition 및 Docker 자료:
https://github.com/ageitgey/face_recognition
https://github.com/ageitgey/face_recognition/tree/master/docker
https://hub.docker.com/r/animcogn/face_recognition

Dockerfile이 있는 디렉터리에서 이미지 생성:
docker build . -t face

컨테이너 실행 및 포트 연결:
docker run -d -p 8888:8888 face

Jupyter가 실행되는 경우 컨테이너 로그의 접속 주소 확인.
과거 로그 예시: Jupyter Server 1.17.0
과거 주소 예시: http://localhost:8888/lab
위 주소는 현재 접속 주소가 아닙니다.

컨테이너에 root 사용자로 접속하는 과거 명령어:
docker exec -i -t --user root {컨테이너이름} bash

5. 라즈베리파이 경로 설정 기록

다음은 과거 장치 경로이며 현재 파일 위치에 맞춘 설정이 아닙니다.

얼굴 Cascade 경로:
cascade_fn = args.get('--cascade', '/home/<user>/Downloads/smartdoor/src/opencv/data/haarcascades/haarcascade_frontalcatface.xml')

위 파일명은 고양이 얼굴용 Cascade입니다.
일반 얼굴 검출 실험 파일은 haarcascade_frontalface_alt.xml을 사용합니다.

눈 Cascade 경로:
nested_fn = args.get('--nested-cascade', '/home/<user>/Downloads/smartdoor/src/opencv/data/haarcascades/haarcascade_eye.xml')

Fallback 데이터 경로:
cam = create_capture(video_src, fallback='synth:bg={}:noise=0.05'.format(cv.samples.findFile('/home/<user>/Downloads/smartdoor/src/opencv/samples/data/lena.jpg')))

로컬 저장:
cv.imwrite('self camera test1.jpg', vis)

저장 대상은 얼굴만 자른 이미지가 아닌 전체 프레임입니다.
실행 시 현재 작업 디렉터리에 같은 파일명으로 덮어씁니다.
담당 기능 확인 파일: archive/experiments/facedetect_10_13.py
